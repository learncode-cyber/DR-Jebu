# লাইভ যাচাই চেকলিস্ট (Phase D)

এই চেকলিস্ট প্রতিটি বাহ্যিক সংযোগের জন্য আলাদা। কোনো সংযোগ লাইভে এই ধাপগুলো পাস না করা পর্যন্ত তাকে "যাচাই হয়েছে" বলা হবে না।

**নিয়ম:**
- Password, API token, Page token বা App Secret কখনো চ্যাটে পাঠাবেন না। সবকিছু অ্যাডমিনের **সাইট সেটিংস** বা নির্ধারিত পাতায় বসাবেন।
- প্রতিটি ধাপের "সফল হলে দেখার ফল" মিললে ✅ দিন। না মিললে থামুন এবং স্ক্রিনের লেখাটি পাঠান (টোকেন ছাড়া)।
- সবশেষে লগ পাতা (**লগ**) দেখুন; নতুন ত্রুটি থাকলে সেটি লিখে রাখুন।

## ১. সিস্টেম ও Cron (সবার আগে এটি)

**কেন:** Gemini কিউ, Facebook কিউ, কমেন্ট খসড়া, স্বয়ংক্রিয় পাঠানো, রিমাইন্ডার সবই `app/cron/dispatch.php` থেকে চলে। এটি না চললে কিছুই চলবে না।

1. Hostinger hPanel → **Advanced → Cron Jobs** খুলুন।
2. নতুন Cron যোগ করুন:
   - Schedule: প্রতি ৫ মিনিট (`*/5 * * * *`)
   - Command: `/usr/local/bin/php /home/<আপনার-ইউজার>/domains/drjebunnesa.online/public_html/app/cron/dispatch.php >/dev/null 2>&1`
   (পথটি File Manager-এ `app/cron/dispatch.php` ফাইলের আসল পথ দেখে নিন।)
3. ৫ মিনিট অপেক্ষা করুন।
4. অ্যাডমিন → **সিস্টেম মনিটর** খুলুন।

**সফল হলে দেখার ফল:** "শেষ cron চলেছে" সময়টি সাম্প্রতিক দেখাবে (১০ মিনিটের মধ্যে) এবং কোনো "critical" সতর্কবার্তা থাকবে না।
অ্যাডমিন → **Facebook পাঠানোর কিউ** পাতায় উপরে "সর্বশেষ কিউ-চালানো" সময়টিও আপডেট হবে।

**ব্যর্থ হলে:** সতর্কবার্তা দেখাবে "১৫ মিনিটের বেশি সময় ধরে চলেনি"। Cron-এর পথ ও PHP সংস্করণ (8.3) যাচাই করুন।

## ২. Gemini (AI)

**আগে:** Google AI Studio থেকে একটি Free-tier API key নিন। Key কোথাও লিখে বা পাঠিয়ে রাখবেন না।

1. অ্যাডমিন → **Gemini এআই** খুলুন।
2. **Credential যোগ করুন:**
   - Label: যেমন `Project A key`
   - API key: আপনার key (এটি একবারই বসান; এরপর শুধু মাস্ক দেখাবে)
   - Google Cloud Project ID: আপনার প্রজেক্টের ID
   - Environment: production; Billing: free
3. যোগ হওয়ার পর **Verify** চাপুন।

**সফল হলে দেখার ফল:** credential-এর পাশে "ok" দেখাবে এবং মডেলের তালিকা আসবে (models.list)। ব্যর্থ হলে বার্তা দেখাবে (যেমন "API key দেখতে সঠিক নয়" বা "permission denied")।

4. **Routes/Settings:** Active project হিসেবে এই প্রজেক্ট নির্বাচন করুন। Daily cap ২০০, RPM cap ৮ রাখুন (ডিফল্ট)।
5. **Run queue** চাপুন। ছোট একটি কাজ আসবে।

**সফল হলে দেখার ফল:** Jobs তালিকায় কাজটি "completed" হবে এবং Usage-এ এক অনুরোধ যোগ হবে।
**429 (quota) এলে:** কাজটি "waiting_quota" হবে এবং Google-এর রিসেট সময় (Pacific midnight) দেখাবে। আবার চেষ্টা করবেন না, অপেক্ষা করুন।
**Paid use:** চালু করবেন না, যতক্ষণ না আপনি নিশ্চিত যে বিলিং সেট আছে। এটি বন্ধ থাকা অবস্থায় paid key ব্যবহার হয় না।

## ৩. Facebook Page (পোস্ট, প্রথম কমেন্ট, কমেন্ট, Messenger)

**আগে যা লাগবে (আপনার নিজের Facebook Developer Account-এ):**
- Meta App ID ও App Secret
- Facebook Page ID
- Page Access Token (দীর্ঘমেয়াদী, Page-এর জন্য)
- Meta App Review: `pages_manage_posts`, `pages_read_engagement`, `pages_manage_engagement`, এবং Messenger-এর জন্য `pages_messaging` (আপনার অ্যাপ লাইভ মোডে থাকতে হবে)

### ৩.১ সেটিংস
1. অ্যাডমিন → **সাইট সেটিংস** → "Facebook Messenger" গ্রুপ।
2. Meta App ID, Meta App Secret, Page ID, Page Access Token বসান। Secret ফিল্ড খালি রাখলে আগেরটি থাকে।
3. Graph version: ডিফল্ট (v26.0) রাখুন।

**সফল হলে:** সেটিংসে "সংরক্ষিত আছে (…)" দেখাবে, পুরো টোকেন নয়।

### ৩.২ Webhook
1. Meta Developer → আপনার App → Webhooks → Page → subscribe করুন: `messages`, `messaging_postbacks` এবং **`feed`** (কমেন্টের জন্য)।
2. Callback URL: `https://drjebunnesa.online/fb-webhook.php`
3. Verify token: সাইট সেটিংস-এর "Webhook Verify Token" ফিল্ডে যা বসাবেন, ঠিক সেই লেখাটিই Meta-তে দিন।

**সফল হলে:** Meta-তে "Verified" দেখাবে এবং Page-এ নতুন একটি কমেন্ট দিলে অ্যাডমিন → **Facebook কমেন্ট (অনুমোদন)**-এ ১–২ মিনিটের মধ্যে আসবে।

### ৩.৩ উৎস-পোস্ট (প্রথম টেস্ট)
1. অ্যাডমিন → **Facebook পোস্ট (উৎস থেকে)** → নতুন উৎস-নোট যোগ করুন (নাম ও ছোট সারাংশ; URL দেবেন না)।
2. খসড়া তৈরি হলে পড়ে দেখুন, তারপর **প্রকাশ করুন** চাপুন।

**সফল হলে দেখার ফল:**
- Page-এ পোস্টটি মূল পোস্ট হিসেবে আসবে (URL ছাড়া, উৎসের নাম সহ)।
- তার নিচে প্রথম কমেন্ট: "অ্যাপয়েন্টমেন্ট নিতে: https://drjebunnesa.online/appointment"
- অ্যাডমিন → **Facebook পাঠানোর কিউ**-তে দুটি কাজ "সম্পন্ন" দেখাবে।

**ব্যর্থ হলে:**
- "কিউ"-তে কাজ "আবার চেষ্টা হবে" (অস্থায়ী) বা "ব্যর্থ (থেমে গেছে)" (স্থায়ী) দেখাবে।
- স্থায়ী ত্রুটি (যেমন code 190) হলে Page token মেয়াদোত্তীর্ণ; নতুন token বসান। "আবার পাঠান" বোতামটি ব্যবহার করুন।
- পোস্ট হয়েছে কিন্তু কমেন্ট যায়নি হলে, কিউ-তে কমেন্ট কাজটিই আবার চেষ্টা হবে। পোস্ট দ্বিতীয়বার যাবে না।

### ৩.৪ কমেন্ট অনুমোদন (প্রথম টেস্ট)
1. Page-এ একটি সাধারণ কমেন্ট দিন (যেমন "চেম্বার কখন খোলা?")।
2. অ্যাডমিন → **Facebook কমেন্ট (অনুমোদন)** → খসড়া পড়ুন → **অনুমোদন ও পাঠান**।

**সফল হলে:** Page-এ উত্তর কমেন্ট হিসেবে আসবে এবং Messenger-এ এক বার ব্যক্তিগত উত্তর যাবে (৭ দিনের মধ্যে)।
চিকিৎসাবিষয়ক কমেন্ট (ওষুধ, রোগ, উপসর্গ) কখনো AI খসড়া করবে না। সেগুলো আপনার কাছে "হোল্ড" থাকবে।

### ৩.৫ স্বয়ংক্রিয় পাঠানো (ঐচ্ছিক, এখন বন্ধ রাখুন)
- সাইট সেটিংস → `fb_comments_auto_send` ও `fb_auto_from`। দুটি সেট না হলে কিছু পাঠানো হবে না। সুপারিশ: আপনি কমপক্ষে ২ সপ্তাহ নিজে অনুমোদন করে দেখুন।

## ৪. Telegram (বিজ্ঞপ্তি)

1. Telegram-এ @BotFather → `/newbot` → token নিন।
2. বটকে আপনার গ্রুপ/চ্যানেলে অ্যাডমিন করুন।
3. chat id বের করুন (টোকেন বদলে): `https://api.telegram.org/bot<TOKEN>/getUpdates`
4. `app/config.php`-তে `TELEGRAM_BOT_TOKEN` ও `TELEGRAM_CHAT_ID` বসান (এই ফাইল সার্ভারে, চ্যাটে নয়)।

**সফল হলে:** একটি নতুন অ্যাপয়েন্টমেন্ট বা টেস্ট বার্তা টেলিগ্রামে আসবে। ব্যর্থ হলে সিস্টেম মনিটরে সতর্কবার্তা দেখাবে।

## ৫. অনুমোদিত মেডিকেল উৎস ও ডাক্তারের অনুমোদন

1. অ্যাডমিন → **অনুমোদিত মেডিকেল উৎস**।
2. প্রতিটি উৎসের শর্ত (Terms) নিজে পড়ুন। তারপর ব্যবহারের ধরন নির্বাচন করে **শর্ত যাচাই হয়েছে** চাপুন।
   (সরকারি RSS/API থাকলে সেটি; না থাকলে "পাবলিক তথ্য (শর্ত মেনে)"।)
3. নতুন গবেষণা যোগ করুন: উৎস, শিরোনাম, https লিংক (ওই উৎসের ডোমেইনের), নিজের ভাষায় সারাংশ, তারিখ।
4. আপনি (ডাক্তার) পড়ে **অনুমোদন** করুন। বাতিল হলে "বাতিল" চাপুন।

**সফল হলে:** অনুমোদিত আইটেম "ডাক্তার অনুমোদিত" দেখাবে। শুধু এগুলোই পরে ব্লগ/পোস্টে ব্যবহার হবে।
**ব্যর্থ হলে:** "URL অবশ্যই https…" বার্তা দেখাবে; ডোমেইন ভুল হলে ঠিক করুন।

## ৬. Google Search Console ও Bing

1. Google Search Console-এ সাইট যোগ করুন ("URL prefix": https://drjebunnesa.online)। Verification code নিন (HTML tag)।
2. অ্যাডমিন → **সাইট সেটিংস** → "Google verification" ফিল্ডে শুধু code বসান।
3. GSC-তে Verify চাপুন। তারপর **Sitemaps** → `https://drjebunnesa.online/sitemap.xml` জমা দিন।
4. Bing Webmaster Tools-এ একই কাজ, Bing verification code দিয়ে।

**সফল হলে:** GSC-তে "Verified" এবং sitemap "Success" দেখাবে।
**নোট:** এই সাইট GSC-এর API ব্যবহার করে না। ডেটা দেখতে আপনি GSC ওয়েবসাইটে যাবেন।

## ৭. LinkedIn

**আগে:** LinkedIn Developer App-এ Redirect URL যোগ করুন: `https://drjebunnesa.online/jebu-cp-3hr3f/linkedin-callback.php`। Products: "Share on LinkedIn" (w_member_social)।

1. সাইট সেটিংস → LinkedIn Client ID ও Client Secret বসান।
2. অ্যাডমিন → **LinkedIn পোস্ট** → **LinkedIn সংযুক্ত করুন** → LinkedIn-এ অনুমতি দিন।
3. একটি খসড়া লিখুন → **পোস্ট করুন**।

**সফল হলে:** আপনার LinkedIn প্রোফাইলে পোস্ট দেখাবে এবং অবস্থা "পোস্ট হয়েছে"।
**ব্যর্থ হলে:** সংযোগ বিচ্ছিন্ন থাকলে আবার সংযুক্ত করুন। মেয়াদ শেষ হলে অ্যাডমিন সতর্কবার্তা দেখাবে।
**নোট:** LinkedIn পোস্ট এখনো কিউ-তে নেই; পোস্টটি সরাসরি যায়।

## ৮. TikTok

**আগে:** TikTok for Developers-এ app তৈরি, Redirect URL: `https://drjebunnesa.online/jebu-cp-3hr3f/tiktok-callback.php`, Content Posting API চালু।

1. সাইট সেটিংস → TikTok Client Key ও Client Secret বসান।
2. অ্যাডমিন → **TikTok ভিডিও** → **TikTok সংযুক্ত করুন** → অনুমতি দিন।

**সতর্কতা:** TikTok-এর app audit শেষ না হলে পোস্ট শুধু "Private" হবে। Public পোস্ট করার আগে TikTok-এর audit শেষ করতে হবে (আপনার দায়িত্ব)।
